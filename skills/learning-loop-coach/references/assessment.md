# 题集、可靠批改与反馈

## 命题前冻结范围

建立简短蓝图：学习目标、已学课次、各主题题数、概念/应用/迁移层级、题型、时间预算、语言与评分规则。范围卷与全考纲模拟明确区分。材料只有目录可读时，仅作章节索引，不能称“根据全书原题改编”。

题量按用户请求，例如90题必须交付90个实质题目，不能只给模板。不必一律英文/单选；资格考试按核验的格式，实用技能还需独立任务。所有权威考试题目宣称要有依据，默认原创模拟，不使用泄露题库。

## 命题质量门槛

- 单选只有一个最佳答案；明示假设、上下文和版本，防止多个选项在合理解释下都正确。
- 干扰项来自常见误解，尽量长度、句式和具体程度相近，避免正确项总是最长或总带限定语。
- 答案位置可分散，但不要以字母配额牺牲题意。不能把正确字母循环当题库质量。
- 包含真实的新情景和必要读图/代码/数据解读，不只换名字重复每日原题。
- 每题有正确答案与依据，说明其余选项为何不适用；标注目标/课次、来源访问边界与复习入口。
- 检查题目相互泄露答案、越界考点、重复题干、编号、选项数、答案覆盖和总分。
- 没有试测就称“预期难度”，不声称心理测量标定或真实通过率预测。

交付试卷、独立解析和答题卡；可分批交卷。用户尚未完成部分不在评阅回复中泄露其答案，除非明确要求解释/收藏该题。若提前展示答案，在后续attempt中记录已接触答案，避免当全新闭卷证据。

## 版本与批改

生成后固定exam ID/version、题号、选项顺序及key，不在评阅时重新随机化。先读实际交付文件而不是凭生成脚本印象批改。用户提交区间含端点：40–70有31题；41–70有30题。数量或映射不一致时停止判分，保留原串并问清，不能根据猜测自动移一题。

支持工具：`scripts/grade_mcq.py`只批改单选，Python 3标准库，无网络、无写文件。读取与已发布版本对应的JSON key；输出JSON结果到stdout，由助手经核对写入attempt。不会生成题目或决定错误原因。

```text
python scripts/grade_mcq.py --key <key.json> --start 41 --end 70 --answers "ABCDD ..." --exam-version v1
```

key格式：

```json
{"exam_id":"demo","version":"v1","questions":[
  {"id":1,"answer":"B","options":["A","B","C","D"],"topic":"concept","points":1}
]}
```

题号必须为正整数且唯一。`--answers`使用紧凑字母串或用空格、逗号、分号隔开，`?`代表区间内明确跳过；编号式回答由助手先核对并转录，不能盲目删除数字。支持任意正分值；默认1分；不支持多选/负分/主观评分，这些需另用明确rubric。

分开输出：本次分数/本次区间满分、实际已答正确率、跳过题数、尚未提交范围。累计仅合并同版本不同题号的首次结果；重考记录为独立attempt，除非用户选择“最新成绩”视图，不能叠加重复题提高分母。更正答案时保留版本/勘误和受影响成绩，不静默改key。

## 反馈

先给结果，再给错题表与解释。区分知识错误、关系/步骤错误、上下文错误、语言误读、填答错误与猜对；只凭字母不能确定心理原因。正确题可指出有证据的进步，但不能据一题永久关闭薄弱点。

高分只反映本次任务，在目标需要时安排延迟回忆及新情境应用。低分先检查题目歧义和先修缺口，再局部补救；不要自动阻止所有新课。主观题先rubric后评分，列出观察到的证据与未满足项，教师代写不计学生独立分。

评阅后按[记录规则](records.md)保存attempt与复习队列；未答题和未提供时长保持未知。若用户要求错题集，将原题、选择、解析和复测状态一起整理，而不只列题号。
